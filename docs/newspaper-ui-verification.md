# 报纸风格前端与 MiMo 接入验收

日期：2026-10-10。

前端采用暖纸色、宋体报头、双线分隔、头条与三栏阅读布局；保留生成简报、
重建画像、反馈写回和本地反馈收集。新增「全部条目 / 贴合兴趣 / 开眼界」栏目切换。
按配置显示阅读比例，显示服务端模型供应商、模型名及密钥配置状态。

MiMo 使用独立的 MIMO_API_KEY / MIMO_BASE_URL / MIMO_MODEL 配置，优先级高于旧网关。
密钥只保存在被 Git 忽略的本地 .env，不进入页面、API 状态响应或此验收记录。
本机 Obsidian 配置从 WSL 路径调整为现有 Windows 路径。

验证结果：

- 32 项 pytest 测试通过；修改模块的 Ruff 检查通过。
- MiMo `mimo-v2.6-pro` 真实返回 JSON，约 3.8 秒。
- 真实调用现有 `rank_items`：合成画像 + 3 条仓库示例候选，3/3 获得有效分数和理由，约 10.23 秒。
- 浏览器栏目筛选分别为 3 / 7 条；反馈写回成功，切换栏目与刷新后保留，再点可取消。
- 浏览器「只收集反馈」流程完成，新增 4 条示例反馈，无错误。
- 1366×768、1920×1080、390×844 均无页面横向溢出，截图已目视检查。
- 构建 wheel 包含 `infoflow/webapp/__init__.py`，安装后可携带前端。

截图位于本地 `docs/newspaper-qa/`，使用 `examples/sample-digest.md` 的隔离副本，
页面明确标记为版式验收。示例文章、分数和画像不代表真实采集结果。
此轮没有执行完整的多来源抓取或重建用户画像，也没有生成今天的真实简报。
